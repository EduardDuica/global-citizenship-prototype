Fractions

A fraction shows part of a whole. The top number (numerator) says how many parts you have; the bottom number (denominator) says how many equal parts make the whole.

To add fractions with the same denominator, add the numerators and keep the denominator: 1/5 + 2/5 = 3/5.

Percentages

A percentage means "out of 100". 50% is half, 25% is a quarter and 10% is one tenth.

To find 10% of a number, divide it by 10. To find 25%, divide by 4. So 25% of 80 is 20.

Intro to Algebra

In algebra a letter stands for an unknown number. To solve x + 4 = 10, do the same thing to both sides: subtract 4 to get x = 6.

Always check your answer by putting it back into the original equation.

Area and Perimeter

Perimeter is the distance around a shape. Area is the space inside it.

For a rectangle, perimeter = 2 x (length + width) and area = length x width.

What is a Computer?

A computer takes in data (input), processes it, stores it and gives a result (output). Keyboards and mice are input devices; screens and speakers are output devices.

The CPU is the "brain" that follows instructions, and memory holds the data it is working on.

Algorithms

An algorithm is a step-by-step set of instructions for solving a problem, like a recipe. Computers need precise steps in the correct order.

A flowchart is a diagram that shows the steps of an algorithm using boxes and arrows.

Binary and Variables

Computers store everything as binary, using only 0s and 1s. The binary number 101 is 4 + 0 + 1, which equals 5.

In programming, a variable is a named box that stores a value, such as score = 10. The value can change while the program runs.
